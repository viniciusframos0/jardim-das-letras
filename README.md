# Jardim das Letras 🌻

Dever de casa de Língua Portuguesa (2º ano, 1º dia – poema *Leilão de Jardim*) transformado em jogo para crianças de 7 anos.

**Jogar:** https://viniciusframos0.github.io/jardim-das-letras/

- Trilha com 6 fases: o poema, primeira letra, última letra, contar letras, letras gêmeas e cestas de palavras
- Leitura em voz alta das perguntas (🔊)
- Estrelas e progresso salvos no aparelho
- No final, as respostas para copiar na folha

Funciona no navegador do celular, sem instalar nada.
